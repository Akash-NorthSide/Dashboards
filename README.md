# Dashboards

Auto-updating tracking dashboards built by NorthSide. One folder per brand.

| Brand | Dashboard | Updates |
|---|---|---|
| Sujata | [Amazon Rank Tracker](https://akash-northside.github.io/Dashboards/Sujata/Sujata_Rank_Dashboard.html) | Daily, after each scan |
| Sujata | [Amazon Performance Dashboard](https://akash-northside.github.io/Dashboards/Sujata/Sujata_Amazon_Performance_Dashboard.html) | Weekly, with the weekly report |
| Elevens Coffee | [Coffee Pods Market Tracker](https://akash-northside.github.io/Dashboards/ElevensCoffee/Elevens_Coffee_Pods_Market_Share_Dashboard.html) | Monthly, after each market scan |
| FunPops | [Daily Sales & Marketing Report](https://akash-northside.github.io/Dashboards/FunPops-DSR/FunPops_DSR_Dashboard.html) | Daily, after each DSR run |
| Oddy Uniwrap | [Daily Sales & Marketing Report](https://akash-northside.github.io/Dashboards/Oddy-Uniwrap-DSR/Oddy_Uniwrap_DSR_Dashboard.html) | Daily, after each DSR run |
| Gluman | [Daily Sales & Marketing Report](https://akash-northside.github.io/Dashboards/Gluman-DSR/Gluman_DSR_Dashboard.html) | Daily, after each DSR run |
| Elevens Coffee | [Daily Sales & Marketing Report](https://akash-northside.github.io/Dashboards/Elevens-Coffee-DSR/Elevens_Coffee_DSR_Dashboard.html) | Daily, after each DSR run |

Every dashboard is encrypted (AES-256-GCM). The data stays unreadable without the password.
Crawlers and AI bots are blocked by `robots.txt`, and each page carries `noindex` tags.
